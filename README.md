## 站点结构

- `index.html`：主页内容与元数据
- `styles.css`：响应式视觉系统
- `assets/`：头像、favicon 与 Open Graph 分享卡
- `resume/caiyuyang-ai-infra-resume.pdf`：公开的一页中文简历

站点无需构建步骤；更新内容或简历后直接提交到 `main` 分支即可发布。
